# 🇧🇩 Bangladesh & Indian IPTV Scraper

এটি একটি স্বয়ংক্রিয় M3U প্লেলিস্ট স্ক্র্যাপার যা বাংলাদেশী এবং ভারতীয় টিভি চ্যানেলের লিংক খুঁজে বের করে এবং প্রতি ঘণ্টায় আপডেট করে।

## ✨ বৈশিষ্ট্য

- 🔄 **প্রতি ঘণ্টায় স্বয়ংক্রিয় আপডেট** - GitHub Actions দ্বারা পরিচালিত
- 🇧🇩 **বাংলাদেশী চ্যানেল** - News, Entertainment, Sports
- 🇮🇳 **ভারতীয় চ্যানেল** - Star, Colors, Zee, DD
- 📺 **50+ লাইভ চ্যানেল** - HD মানের লিংক
- 📝 **M3U ফরম্যাট** - সব IPTV প্লেয়ারে সামঞ্জস্যপূর্ণ
- 🔐 **জনসাধারণের জন্য উন্মুক্ত** - কোনো লুকানো কন্টেন্ট নেই

## 📥 ব্যবহার করার উপায়

### VLC Media Player
1. **VLC** খুলুন
2. **Media → Open Network Stream** যান
3. এই লিংক পেস্ট করুন:
```
https://raw.githubusercontent.com/mdislammondol160-del/Bangladesh-IPTV-Scraper/main/playlist.m3u
```
4. **Play** এ ক্লিক করুন

### Android (OTT Navigator)
1. **OTT Navigator** অ্যাপ খুলুন
2. **Add Playlist** এ ক্লিক করুন
3. URL পেস্ট করুন এবং Add করুন

### অন্যান্য IPTV প্লেয়ার
- **IPTV Smarters**
- **Televizo**
- **NS Player**
- **Kodi**
